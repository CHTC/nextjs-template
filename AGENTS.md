## Code standards

Before writing or changing code, read `.ai/instructions.md`. It holds this repository's standards for Next.js, React components, MUI and the `sx` prop, naming and accessibility, and applies to every `.ts`, `.tsx`, `.js`, `.jsx` and `.css` file. Where it and the Next.js docs in `node_modules/next/dist/docs/` disagree on an API, the docs for the installed version win.
